# 月经不调，不要慌，找准病因，对因治疗

> 更新时间：2026-09-16 (UTC+8)

正常有排卵的妇女在一个卵巢周期的末期，如果所排出的卵子未受精，则黄体退化，体内雌、孕激素水平随之下降，出现子宫出血，临床上表现为月经。正常的月经有规律的周期性，周期时间为21-37天。经期出血的时间持续3-7天。平均每周期的出血量为20-60ML，超过100ML的出血则为月经量过多。

    上面我们说到了正常的月经，那么什么是月经不调呢？当然就是正常的月经出现了问题，表现在月经量的改变或是月经周期的改变。

1.     月经量改变---月经量过多

     正常月经的出血量大概在20-60ML,每个月出血量超过100ML我们称为月经量过多。平时月经量正常，突然出现月经量过多可能是病理情况。一般能引起月经过多的情况，包括有全身系统性疾病，如重度贫血、血小板减少、凝血功能异常等。此外，某些妇科疾病也可能导致月经量多，如子宫肌瘤、子宫内膜异位症等等。

2.     月经量改变---月经量过少

     某些情况下，月经量减少也是一种病理情况，如子宫内膜本身的病变，内分泌方面的改变等等。此外，生活习惯和方式的改变，情绪的变化及精神刺激等均可能导致月经量减少。

3.     月经周期的改变----月经推迟

     某些女性平素月经周期规则，但月经突然推迟，甚至出现闭经，这个时候应该要引起重视了。首先要排除怀孕的可能，除外妊娠，还有其他一些原因可能导致月经推迟，包括有本身的一些慢性疾病，如慢性肝炎、肿瘤、甲状腺功能异常等；还有内分泌异常引起的月经推迟，最常见的就是多囊卵巢综合症；还有某些药物引起的月经不调，包括长期服用避孕药、使用紧急避孕药等。月经推迟时，先不要慌张，找出原因才能对因治疗。

4.     月经周期的改变----月经提前

     平素周期规则的女性突然出现月经周期的缩短，月经的提前，可能是卵巢功能开始衰退的信号。主要原因可能是下丘脑-垂体-卵巢轴的功能不稳定或是缺陷，引起卵巢功能的进一步减退。此外，还有某些器官的器质性改变也可能导致：例如某些生殖器局部的炎症、肿瘤或是发育异常；甲状腺功能的改变等等。

     当正常月经发生改变时，大家不要慌张，找出正确的病因，对因治疗，大部分人的月经可以恢复正常。

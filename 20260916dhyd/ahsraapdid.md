# 南阳市第一人民医院积极稳步推进医共体建设工作

> 更新时间：2026-09-16 (UTC+8)

南阳市第一人民医院始终坚持“以人民健康为中心”，以疾病预防和健康促进为核心，紧盯“大病不出区、小病就近看、未病共同防、群众更健康”目标，深入推进卧龙区紧密型区域医共体建设，区域卫生健康服务能力持续提升取得长足发展。

市委深改办、市卫体委领导深入卧龙区医疗

健康服务集团总医院调研指导工作
     3月4日，市委深改办赵坤科长、市卫体委杨洋科长、市卫体委韩溁一行来卧龙区医疗健康服务集团总医院南阳市第一人民医院考察指导工作，集团党委书记张继中、总院长马磊、区委改革办副主任杨双才等相关人员陪同。

 

考察组一行先后前往卧龙区医疗健康集团办公场所、远程检验中心、消毒供应中心等实地察看，翻阅资料，听取了集团、双向转诊、对口支援、智慧医疗、七大共享中心等工作汇报，详细了解集团运营情况，并召开高质量推进卧龙区医共体工作专题会。 

通过实地考察，考察组对卧龙区医共体建设工作取得的成绩和亮点给予充分肯定，特别是“4+1”一体化管理模式（4即医疗服务一体化、妇幼保健一体化、疾病防控一体化、卫生监督一体化，1即中医药融入）。下一步我们将继续总结经验，按照省市区整体工作部署，再接再厉、精益求精、扎实稳步推进医共体建设工作，让辖区群众真正享受到医共体建设带来的便捷和实惠。

我院举办卧龙区医疗健康服务集团药事管理专项培训会

 3月4日下午，卧龙区医疗健康服务集团在总医院南阳市第一人民医院召开药事管理专项培训会议，总医院副院长余珊容出席并致辞，医共体各成员单位药事管理分管领导、卧龙区医疗健康服务集团药事管理与药物治疗学术委员会委员、药事管理主任及相关人员参会。

 副院长余珊容指出药事管理工作是医疗机构的一项重要工作，随着我国《"健康中国2030"规划纲要》的推进落实和医药卫生体制改革的逐步深化，越来越多与医院药学领域相关的政策和法规相继出台，对医院药学的发展产生了深远的影响，需要加强药事管理工作，保障大众用药安全。

 培训会上，集团总医院主管药师华素讲解了《处方管理办法及处方点评》、副主任药师张毅讲解了《药品采购储存养护和调剂管理》、主管药师庞立峰讲解了《抗菌药物的合理应用》、副主任药师李付波讲解了《2022年医疗机构麻醉药品精神药品应用与管理》，现场气氛热烈，大家踊跃发言。 

培训会结束后，参会人员零距离观摩了总医院南阳市第一人民医院“门诊智慧药房”，对药房便捷服务、药事服务等流程进行了学习。

统一管理 集中核算 统筹运营

医共体财务审计部实行集中统一办公制度

3月7日是卧龙区医疗健康服务集团集中统一办公的日子，一大早集团成员单位财务骨干按时来到总医院财务审计部，开展共同学习，共同协商，共同办公。

集团总医院副院长翟磊参加财务审计部集中办公工作例会，他讲到集团财务审计部为认真贯彻落实好集团党委和总医院关于加强医共体财务管理工作的要求，积极落实统一管理、共同协商的财务管理模式，并科学设置内部岗位分工，对具体承担的会计核算、预算管理、成本管理、资金管理、财务监督、内部控制等财务管理工作做出具体安排，对下一步更好地构建完善“一本账”的财务管理工作具有积极意义。财务审计部主任、医院总会计师李聪艺在集中办公工作例会中说到，如今集团实行定期集中办公，充分发挥了总医院“统一管理，集中核算”的作用。下一步，要共同科学设计各类绩效管理目标，通过加强医共体目标绩效考核，充分调动成员单位工作积极性，更好促进医共体高质量运行。长期参与基层医疗机构财务管理工作的区卫健委经管办张红刚认为，这种集中统一办公形式，不仅加强了相互之间的沟通交流，还有利于提高大家的业务水平，有效提高了财务管理和会计核算的办公效率。医共体财务实行集中统一办公制度，更好地构建完善“一体化”的财务管理，有效提高财务人员业务水平，加强财务人员的沟通交流，大家一致感觉“集中办公真的好！”。

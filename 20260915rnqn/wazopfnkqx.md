# 隆鼻材料总结

> 更新时间：2026-09-15 (UTC+8)

隆鼻材料应用进展
鼻整形术是整形外科开展最多的手术之一，其中隆鼻术又是整形美容开展最多的手术。隆鼻术是利用填充材料置于鼻部软组织与鼻支架之间矫正外鼻形状的手术。随着手术的不断改进，隆鼻材料也随之发展。填充材料总体分三大类：人工合成材料，自体组织移植、组织工程材料。
一、理想隆鼻材料
理想的隆鼻材料应该具备具有以下特点：

1.无毒、无致癌性、生物相容性好，填充物对机体刺激小则发生局部炎症少；

2. 可塑性好，耐生物老化性好不易变形或吸收，可塑性好是使手术效果满意的基础，耐老化使效果持久；

3.放置和取出方便，手术效果不可能每一个都达到百分百，有一定概率进行再次手术，需要材料取出盒放置相对容易点；

 4. 隆鼻后不影响皮肤颜色、外观自然，隆鼻术大多为美容行，因此填充物不应改变皮肤颜色，显得突兀。另外填充材料还应具备其它一些外部条件，如易于消毒灭菌处理；取材方便，材料来源充足；对x线具有可透射性；热及电传导性低等。但是就目前技术还无法做到“鱼与熊掌兼得”，只能根据手术情况和术者要求，依据材料特性进行选折。 
二、各填充材料特点及其应用
1、人工合成材料
医用成形硅胶（硅酮）：由二甲基硅烷聚合成的长链分子聚合物，其生物相容性和稳定性较好，近似软骨的弹性、韧性、支撑强度且价格低廉、取材方便，临床上使用年代较长。但是硅胶在体内“生存”形式是“保存”在集体形成的薄膜内，其位置相对固定而不是永久愈合，易伴发感染，很容易暴露或脱出，异物反应相对严重。较早年代还有使用液态硅橡胶，后因植入体内后难以彻底清除而被临床淘汰。
羟基磷灰石(HA)：以骨和牙齿的主要无机成分为原料的一种注射填充材料。引起成分与机体本身成分相同，故组织相容性好，并发症比硅胶还少。它的优点是：无毒、无致癌性、不易被机体吸收，不会或者很少刺激机体免疫系统，而且HA术后能较好的结合与机体本身的骨结构，看上去自然美观，受者肤色不受影响，创伤极小。该材料的缺点是： ①  填充量对施术者的要求高，术中逐次填充，术中判断效果不利于鼻小柱的成形；② 植入HA后一周该材料才逐渐固化，术后效果很难判断，不利于鼻小柱的成形；③HA植入后与组织紧密“愈着”性，使得取出HA颗粒难度大，易造成较大损伤。

膨体聚四氟乙烯：由许多聚四氟乙烯结和结间细小纤维组成的膨化多孔聚合物，可以看成是硅橡胶假体的传承。但是它与硅橡胶相比，继承了硅橡胶的全部优点，而且较硅胶涩软，在鼻端的支撑强度近似软骨，美观效果和远期固定效果相对理想。周围的血管及肉芽组织长入其微多孔结构中使得假体与身体结合较紧，但是对假体取出没有造成不变。在鼻梁较低、鼻背软组织较少较薄的受术者中该假体尤其适用。该材料也有缺点为：①该材料产品价格不菲，因其生产基本进口，受专利性保护；②该材料质地较软适用蝶形切口置入，术后切口创伤较大，容易留瘢痕。③抗感染力较差，由于微孔的特殊结构，一旦感染，很难彻底根治，必须取出。
胶原薄片：胶原蛋白（也称胶原）是细胞外基质的一种结构蛋白质，英文名“collagen”，由希腊文演化而来，多糖蛋白，呈白色，含有少量的半乳糖和葡萄糖，是细胞外基质（ECM）的主要成分，约占胶原纤维固体物的85%。在医学领域中，胶原蛋白由于具有低免疫原性、纤维的再形成性、强的机械性能和生物可降解性等优点，可制成胶原海绵、胶原膜、人工皮肤、固定化美酶载体和胶原薄片等。Chang C的研究中，认为鼻背整形中使用胶原薄片相对硅胶和聚四氟乙烯可以减少术后并发症和异物感。胶原薄片可塑性强，在术中能够获手术需要的厚度和形状。在他们的手术中他们其实大量使用胶原蛋白片也未生明显的移植物吸收或者矫枉过正。在没有或者缺少理想自体移植物的病患情况下，利用胶原薄片是一种不错的选折。
爱贝芙：是包裹着PMMA（聚甲基丙烯酸甲酯）小微球的胶原蛋白液体。Chen L等通过比较爱贝芙，玻尿酸，硅胶在隆鼻术中的应用效果发现，使用硅胶进行手术的案例其并发症和严重程度均高于爱贝芙及玻尿酸组，但玻尿酸手术后的隆鼻效果在1年内逐渐消失，使用爱贝芙的一年后仍能维持效果。但是爱贝芙注射对施术者经验技能要求高，常需多次注射才达到满意效果，如矫枉过正不易恢复。
2、自体组织移植。
自体软骨：在Park JH 研究中，自体肋软骨移植在亚洲人鼻整形术中是用途较广且较可靠的移植材料，但在其用于鼻背部修复时有很小概率弯曲变形，其并发感染的概率也较小。其供体疤痕较小，对美观影响很小，气胸和供体疼痛没有发生。大多数患者对整形术后功能和美观满意，移植物显露、移植物移位、移植物吸收没有出现。但是自体软骨取材不方便，易造成二次损伤，且供区美观受影响。
自体脂肪：自体脂肪组织具有组织相容性好，无排斥反应的优点。但行自体脂肪隆鼻术后吸收较明显(体积缩小40 ～50 )，所以术后早期鼻外形较大，对吸收率较大的病例需多次注射才能达到满意效果。
自体第3磨牙：自体第3磨牙也是非常好的自体填充材料，其取材较为方便，手术后创伤也非常小。据有关资料显示，人体第3磨牙长17mm，宽约10mm，呈“叶片状” ，很适合做隆鼻假体，且此材料可低温保存，对手术时间的要求不是很严格。但利用第3磨牙，受术者必然要承受拔牙的痛苦以及可能引来的并发症困扰，因而该材料在临床上使用较少。
为了缓解取材带来的矛盾，临床上也采用异体移植物和自体移植物相结合的办法。Li SH报导了在亚洲人中采用异体移植物和自体移植物相结合用于在皮肤菲薄的患者中取得良好效果，避免了皮肤薄的患者中移植物外露，移植物变形的出现。同时该法还能减少人工合成材料在隆鼻术中的并发症。
3、组织工程材料
组织工程是生物材料学、生物医学结合的一门综合学科。科学家利用组织工程原理培养出自然健康的自体组织。以藻酸钙为载体的组织工程骨已在裸鼠皮下获得成功，这为进一步的美学应用奠定良好的基础。Mendelson A 利用细胞归巢和组织工程开发生物活性支架，这个活性支架为多孔双层其上有海藻酸钠、明胶微球包裹的细胞因子，在小鼠体内能够使细胞聚集于在鼻背，同时也能诱导吸引细胞软骨分化。这个研究提示利用细胞归巢和组织工程制造隆鼻替代材料的可能性。这样做出来的组织工程骨材料与自体骨十分接近，可无抗原性。同时二次手术的困扰、取材量无限制，应用价值高。
已有的人工合成材料和自体移植材料都面临着各自的局限性，组织工程在材料上的前景十分可观。近年来3D打印技术迅猛发展，人们可以根据需要打印出任意形状和样式。通过电镜技术的帮助下，可以很好的观察软骨细胞纤维的排列，了解其生物力学曲线特性，可以在计算机中构建出与人类软骨的骨架从宏观到微观都一致的三维模型，在利用合适的生物材料3D打印出来。利用记忆金属的特性人们已经在某些领域实现4D打印，将来借助电镜技术等在蛋白质、多肽乃至分子水平上观察和编辑，生物技术上的4D打印也会实现，为隆鼻术提供新的方向。
